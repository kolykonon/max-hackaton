# Проверка результата

## Автоматические проверки

`npm test` — 11 пройденных проверок Node; `python3 -m unittest discover -s tests -p 'test_*.py'` — 3 пройденных проверки Python.

- 405 учреждений, уникальные ID, 84 значения региона и сохранение всех исходных полей.
- 8 допустимых статусов на центр, побайтовая стабильность повторной генерации.
- Пример 8/23 при 4 неизвестных из 27, отсутствие данных, пороги 25%/60%, отсутствие «худший центр = красный регион».
- Все нераспознанные адреса имеют null-координаты; адресные точки имеют происхождение OSM.
- Корпус/строение не игнорируются; одноимённый населённый пункт другого региона не даёт ложную точку; центроид города отклоняется.
- Разные объекты Москвы и Московской области; обе региональные связи BS-0028.
- 85 геометрий, сохранены все исходные острова/части; TopoJSON имеет общие дуги соседей.
- Point-in-polygon для Москвы, Владивостока, Анадыря, переход через 180°, внутренние отверстия.
- Кластеры сохраняют все точки, включая совпадающие и цепочки соседних точек.
- Ближайшие центры независимо от региона, исключение null-координат, километры по прямой.
- 132 района Москвы; районы без центров серые.

## Проверки в браузере

Проведены на запущенном локальном прототипе инструментами браузера; реальные координаты пользователя не запрашивались.

- Старт: 85 контуров, 405 учреждений. В начальных сетевых ресурсах нет запросов `/data/regions/` — подробные геометрии ленивые.
- Россия → поиск «Москва» → регион: загружаются 132 района и точки центров.
- Поиск «Царицыно» даёт конкретный центр BS-0002; карточка содержит все 8 статусов, контакты, часы и способ записи из справочника.
- Смена O(I) Rh+ на AB(IV) Rh− обновляет подпись карты, список и карточку. Для BS-0002 проверено изменение «Нужны доноры» → «Достаточно» по файлу демоданных.
- Фильтр «Высокая потребность» оставляет только соответствующие центры; учреждение без точки остаётся в списке.
- Клавиатурное открытие/закрытие карточек, выбор группы, фильтр; кнопки масштаба и стрелки перемещения меняют transform карты. Обработчик клика проверен реальными событиями mousePressed/mouseReleased через DevTools, после некорректного позиционирования кликов адаптером встроенного браузера.
- Совпадающий кластер: в памяти тестового браузера временно совпали координаты BS-0001, BS-0002, BS-0003. Открытие кластера показало все три ID; выбор BS-0003 открыл соответствующую карточку. Файлы справочника не изменялись, тестовый fetch удалён перезагрузкой.
- Геолокация: временный mock браузерного API с координатами Москвы и accuracy=42 определил Москву, показал ±42 м, маркер и расстояния по прямой. Список включал Московский областной центр и другие учреждения за административными границами.
- Ошибки разрешения (1), недоступности (2), тайм-аута (3) показывают разные понятные сообщения и возвращают кнопку в активное состояние.
- Тестовая точка 0°,0° показывает сообщение о нахождении вне покрытия и точность, не присваивая регион.
- Ширины 390 и 1440 px: document.scrollWidth совпадает с innerWidth; 8 переключателей доступны. На 390 px карта, управление и список расположены последовательно. Снимок: `mobile.png`.
- Временные подмены геолокации и координат удалены перезагрузкой. Обычный запуск использует сохранённые данные и реальный браузерный API только после нажатия пользователя.

## Не подтверждалось

Реальная актуальность контактов/донорского приёма, точность входа в здание, работа на физическом телефоне и боевой backend. Исторические обзорные границы 2013 года не выдаются за актуальные административные границы. Нераспознанные 202 адреса остаются ограничением данных.
