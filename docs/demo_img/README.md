# Макеты мини-приложения «Капля» в MAX

26 концептуальных экранов в светлом стиле MAX UI для iOS. Макеты сделаны по файлам `docs/screens`. Для прокручиваемых экранов показана видимая область телефона; некоторые длинные тексты сокращены на изображениях. Исходное ТЗ остаётся источником точных текстов и поведения.
