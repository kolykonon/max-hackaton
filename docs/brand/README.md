# Логотип «Капли»

![Логотип проекта «Капля»](kaplya-logo.png)

`kaplya-logo.png` — исходный файл, предоставленный командой. Размер: 1275 × 1233 пикселя, PNG с прозрачностью. Файл сохранён без изменения изображения.

| Где используется | Файл |
| --- | --- |
| Исходник для документации и новых материалов | [`docs/brand/kaplya-logo.png`](kaplya-logo.png) |
| Иконка вкладки и иконка для добавления мини-приложения на экран устройства | `frontend/public/kaplya-logo.png` |
| Иконка вкладки и знак в старом прототипе карты | `legacy/russia-map/kaplya-logo.png` |

Копии должны оставаться побайтово одинаковыми с исходником. При замене логотипа обновите все три PNG и проверьте ссылки в `frontend/index.html`, `legacy/russia-map/index.html` и корневом `README.md`.

Аватар бота в MAX задаётся в кабинете платформы отдельно; файл из этой папки можно загрузить туда вручную.
