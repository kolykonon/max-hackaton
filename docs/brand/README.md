# Логотип «Капли»

![Логотип проекта «Капля»](../../frontend/public/kaplya-logo.png)

`frontend/public/kaplya-logo.png` — файл, предоставленный командой. Размер: 1275 × 1233 пикселя, PNG с прозрачностью.

| Где используется | Файл |
| --- | --- |
| Иконка вкладки, мини-приложения и документации | [`frontend/public/kaplya-logo.png`](../../frontend/public/kaplya-logo.png) |
| Иконка вкладки и знак в старом прототипе карты | `legacy/russia-map/kaplya-logo.png` |

Копии должны оставаться побайтово одинаковыми. При замене логотипа обновите оба PNG и проверьте ссылки в `frontend/index.html`, `legacy/russia-map/index.html` и корневом `README.md`.

Аватар бота в MAX задаётся в кабинете платформы отдельно; для загрузки используйте `frontend/public/kaplya-logo.png`.
