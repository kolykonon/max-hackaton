# Экран «Карта» (донорский светофор)

Открывается с экрана «Запись» нажатием на карточку «Донорский светофор». Нижнее меню на этом экране скрыто. Данные в MVP тестовые.

## Структура

```
┌──────────────────────────────┐
│ [←]  Карта                   │  шапка
│ ─────────────────────────────│
│                              │
│      ____________            │
│     /   ( (МСК) )  \___      │
│    |     \ МО /        \     │  карта России
│    |                    |    │  (~65% высоты)
│  (Крым)                /     │
│                   [+][−][◎]  │
│ ● срочно ● мало ● есть ● нет │  легенда
│ ─────────────────────────────│
│  Москва                      │  данные по зоне
│  данные на 24 сентября  Демо │
│                              │
│  1+  1−  2+  2−  3+  3−  4+ 4−│  светофор
│  ●   ●   ◉   ●   ●   ●   ●  ●│  (◉ — выбранная группа)
└──────────────────────────────┘
```

## Как устроена карта

- Карта России разделена на **зоны**. Каждая зона — территория, которую обслуживают донорские центры. Там, где центров много, зоны мельче: например, Москва — отдельная зона внутри, Московская область — зона вокруг неё.
- Каждая зона залита цветом по статусу **выбранной группы крови**.
- Карту можно двигать пальцем и приближать щипком или кнопками «+» / «−».
- Выбранная зона обведена толстой рамкой.

### Цвета

| Цвет | Статус | Подпись в легенде |
|------|--------|-------------------|
| Красный | Кровь нужна срочно | Нужна срочно |
| Жёлтый | Запас небольшой | Мало |
| Зелёный | Запас достаточный | Достаточно |
| Серый | Нет данных | Нет данных |

## Элементы и тексты

### 1. Шапка

| Элемент | Вид | Текст |
|---------|-----|-------|
| Кнопка «Назад» | Стрелка «←» слева | скринридер: «Назад» |
| Заголовок | Жирный | Карта |

### 2. Карта (~65% высоты)

| Элемент | Вид | Текст |
|---------|-----|-------|
| Карта | Зоны залиты цветом, границы тонкие белые | — |
| Кнопки масштаба | «+» и «−», правый нижний угол карты | скринридер: «Приблизить», «Отдалить» |
| Кнопка «Моё местоположение» | Круглая, рядом с кнопками масштаба | скринридер: «Показать моё местоположение» |
| Легенда | Полоса внизу карты, 4 цветных точки с подписями мелким шрифтом | ● Нужна срочно · ● Мало · ● Достаточно · ● Нет данных |

### 3. Данные по выбранной зоне

| Элемент | Вид | Текст |
|---------|-----|-------|
| Название зоны | Жирный | {Москва} |
| Дата | Мелкий серый | данные на {24 сентября} |
| Метка | Мелкий серый на светлом фоне, справа от даты | Демо-данные |

### 4. Светофор по группам крови

Одна строка из 8 групп на всю ширину. Над каждым кружком подпись группы, сам кружок — цвета статуса этой группы в выбранной зоне.

Порядок: **1+ 1− 2+ 2− 3+ 3− 4+ 4−**

| Элемент | Вид | Текст |
|---------|-----|-------|
| Подпись группы | Жирный, по центру над кружком | 1+ … 4− |
| Кружок | ~28 px, цвет статуса | скринридер: «Группа {A(II) положительная}: {нужна срочно}» |
| Выбранная группа | Кружок крупнее, с тёмной обводкой, подпись в фирменном цвете | — |
| Группа пользователя | Под кружком мелкая подпись | ваша |

Кружки нажимаются: выбранная группа определяет, как окрашена карта.

- По умолчанию выбрана группа пользователя из «Личного кабинета».
- Если группа пользователя неизвестна, ничего не выбрано, и каждая зона окрашена по худшему статусу среди всех групп.

## Переходы

| Действие | Куда |
|----------|------|
| «←» или системный «Назад» | Экран «Запись» |
| Нажатие на зону | Зона выделяется, данные и светофор внизу обновляются |
| Нажатие на кружок группы | Группа становится выбранной, карта перекрашивается |
| Повторное нажатие на выбранный кружок | Выбор снимается, карта окрашена по худшему статусу среди всех групп |
| «Моё местоположение» | Карта приближается к зоне пользователя и выбирает её |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Первое открытие | Запрос доступа к геолокации. Если разрешили — выбрана зона пользователя. Если нет — последняя выбранная зона, при первом запуске Москва |
| Загрузка | Серый фон на месте карты со спиннером, кружки светофора серые |
| Ошибка загрузки | На месте карты: «Не удалось загрузить карту» и кнопка «Повторить» |
| Геолокация недоступна | При нажатии «Моё местоположение» уведомление «Не удалось определить местоположение» на 2 секунды |
| Зона без данных | Все кружки серые, под ними текст «Нет данных по этой зоне» |
