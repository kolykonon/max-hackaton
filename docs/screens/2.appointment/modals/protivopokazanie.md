# Модалка «Противопоказания»

Открывается ссылкой «Полный список противопоказаний» на экране «Запись на донорство» и кнопкой «Список противопоказаний» на экране 3 онбординга. Шторка снизу до 80% высоты, фон затемняется, содержимое прокручивается.

## Структура

```
┌──────────────────────────────┐
│            ────              │
│  Противопоказания        [✕] │
│                              │
│  Нельзя сдавать кровь        │
│  • ...                       │
│                              │
│  Нужно подождать             │
│  Ситуация        Сколько     │
│  ...             ...         │
│                              │
│  Перечень утверждён ...      │
│  Полный список на сайте ... ›│
└──────────────────────────────┘
```

## Элементы и тексты

| Элемент | Вид | Текст |
|---------|-----|-------|
| Ручка | Серая полоска сверху | — |
| Заголовок | Крупный жирный | Противопоказания |
| Кнопка закрытия | Крестик справа | скринридер: «Закрыть» |

### Раздел «Нельзя сдавать кровь»

Подзаголовок жирным, ниже список с точками:
- ВИЧ, гепатиты B и C, сифилис, туберкулёз
- Онкологические заболевания
- Болезни крови
- Серьёзные болезни сердца и сосудов, органов дыхания, пищеварения, почек
- Психические расстройства
- Инвалидность I и II группы

### Раздел «Нужно подождать»

Подзаголовок жирным, ниже таблица в две колонки:

| Ситуация | Сколько ждать |
|----------|---------------|
| Алкоголь | 48 часов |
| Антибиотики | 14 дней после окончания приёма |
| ОРВИ, грипп, ангина | 30 дней после выздоровления |
| Прививка | от 10 дней до 1 года, зависит от вакцины |
| Операция | 120 дней |
| Татуировка, пирсинг, иглоукалывание | 120 дней |
| Роды | 1 год |
| Грудное вскармливание | 90 дней после окончания |

### Низ шторки

| Элемент | Вид | Текст |
|---------|-----|-------|
| Подпись | Мелкий серый | Перечень утверждён приказом Минздрава России № 1166н |
| Ссылка | Фирменный цвет, справа «›» | Полный список на сайте Службы крови |

## Переходы

| Действие | Куда |
|----------|------|
| Крестик, свайп вниз или тап по затемнению | Шторка закрывается, пользователь на экране, с которого её открыл |
| «Полный список на сайте Службы крови» | yadonor.ru во внешнем браузере |
