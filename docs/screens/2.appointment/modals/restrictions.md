# Модалка «Почему такие ограничения»

Открывается ссылкой «Почему такие ограничения?» на экране «Запись на донорство». Шторка снизу до 80% высоты, фон затемняется, содержимое прокручивается.

## Структура

```
┌──────────────────────────────┐
│            ────              │
│  Почему такие ограничения [✕]│
│                              │
│  [иконка] От 18 лет          │
│           объяснение...      │
│  [иконка] Вес от 50 кг       │
│           объяснение...      │
│  [иконка] 60 дней между      │
│           сдачами            │
│           объяснение...      │
│  [иконка] Гражданство или    │
│           год в России       │
│           объяснение...      │
│                              │
│  Ограничения нужны, чтобы    │
│  донация была безопасной...  │
└──────────────────────────────┘
```

## Элементы и тексты

| Элемент | Вид | Текст |
|---------|-----|-------|
| Ручка | Серая полоска сверху | — |
| Заголовок | Крупный жирный | Почему такие ограничения |
| Кнопка закрытия | Крестик справа | скринридер: «Закрыть» |
| Пункты | Иконка слева, справа заголовок жирным и объяснение | см. ниже |
| Итог | Мелкий серый внизу | Ограничения нужны, чтобы донация была безопасной и для вас, и для пациента. Окончательное решение о допуске принимает врач. |

### Пункты

| Иконка | Заголовок | Объяснение |
|--------|-----------|------------|
| Паспорт | От 18 лет | Так установлено законом: сдать кровь может только совершеннолетний, который сам даёт согласие на донацию. |
| Весы | Вес от 50 кг | За одну донацию берут около 450 мл крови. Безопасно отдать не больше 12% всей крови в организме, а её объём зависит от веса. Если весить меньше 50 кг, могут резко упасть давление, закружиться голова, возможен обморок. |
| Календарь | 60 дней между сдачами крови | Организму нужно время, чтобы восстановить кровь и запас железа. Если сдавать чаще, можно заработать дефицит железа. |
| Флаг | Гражданство России или год проживания | Так установлено законом: донором может быть гражданин России или иностранец, который законно живёт в России не меньше года. |

## Переходы

| Действие | Куда |
|----------|------|
| Крестик, свайп вниз или тап по затемнению | Шторка закрывается, пользователь на экране «Запись на донорство» |
