# Экран «Запись» (главный)

Первая вкладка нижнего меню. Сюда пользователь попадает после онбординга и при каждом повторном входе.

## Структура

**Вариант А — записи нет:**

```
┌──────────────────────────────┐
│ ┌──────────────────── Демо ┐ │
│ │                          │ │
│ │   [ превью карты ]       │ │  донорский светофор
│ │                          │ │  (~20% высоты)
│ │ Донорский светофор     › │ │
│ │ ● нужна ● мало ● есть    │ │
│ └──────────────────────────┘ │
│                              │
│ ┌──────────────────────────┐ │
│ │ [календарь]              │ │
│ │ У вас нет записи         │ │  карточка записи
│ │ Сдать кровь можно        │ │
│ │ с 12 октября             │ │
│ └──────────────────────────┘ │
│                              │
│ [       Записаться        ]  │  основная кнопка
│                              │
│   [Запись]  [Личный кабинет] │  нижнее меню
└──────────────────────────────┘
```

**Вариант Б — запись есть:**

```
┌──────────────────────────────┐
│ ┌──────────────────────────┐ │
│ │   [ превью карты ]       │ │
│ │ Донорский светофор     › │ │
│ └──────────────────────────┘ │
│                              │
│ ┌──────────────────────────┐ │
│ │ Вы записаны              │ │
│ │ 14 октября, вт, 09:30    │ │
│ │ Цельная кровь            │ │
│ │ Центр крови ФМБА России  │ │
│ │ ул. Поликарпова, 14      │ │
│ │ 🔔 Напомним в чате       │ │
│ │    за день               │ │
│ │ [Перенести] [Отменить]   │ │
│ └──────────────────────────┘ │
│                              │
│   [Запись]  [Личный кабинет] │
└──────────────────────────────┘
```

Если контент не помещается, экран прокручивается. Нижнее меню закреплено.

## Элементы и тексты

### 1. Карточка «Донорский светофор» (~20% высоты)

| Элемент | Вид | Текст |
|---------|-----|-------|
| Превью карты | Картинка-плейсхолдер карты на всю ширину карточки, скруглённые углы | alt: «Карта станций переливания крови» |
| Метка | Правый верхний угол, мелкий текст на светлом фоне | Демо-данные |
| Заголовок | Жирный, под превью слева, справа «›» | Донорский светофор |
| Легенда | 3 цветных точки с подписями, мелкий шрифт | ● Нужна срочно · ● Мало · ● Достаточно |

Карточка нажимается целиком.

### 2. Карточка записи — вариант А (записи нет)

| Элемент | Вид | Текст |
|---------|-----|-------|
| Иконка | Календарь, ~32 px, слева | — |
| Заголовок | Жирный | У вас нет записи |
| Подпись | Мелкий серый. Показывается, только если ещё идёт интервал после прошлой донации | Сдать кровь можно с {дата} |

### 2. Карточка записи — вариант Б (запись есть)

| Элемент | Вид | Текст |
|---------|-----|-------|
| Заголовок | Мелкий, фирменный цвет | Вы записаны |
| Дата и время | Крупный жирный | {14 октября, вт, 09:30} |
| Вид донации | Обычный, слева картинка-капля вида | Цельная кровь / Плазма |
| Клиника | Обычный | {Центр крови ФМБА России} |
| Адрес | Мелкий серый | {ул. Поликарпова, 14} |
| Напоминание | Мелкий серый, иконка колокольчика | Напомним в чате за день до донации |
| Кнопка «Перенести» | Контурная, половина ширины, слева | Перенести |
| Кнопка «Отменить» | Контурная, красный текст, половина ширины, справа | Отменить |

### 3. Кнопка «Записаться»

Основная кнопка, фирменный цвет, на всю ширину, под карточкой записи. Текст: **Записаться**. Показывается только в варианте А.

### 4. Нижнее меню

Активна вкладка «Запись».

### 5. Окно подтверждения отмены

Диалог по центру экрана, фон затемнён.

| Элемент | Текст |
|---------|-------|
| Заголовок | Отменить запись? |
| Текст | {14 октября, 09:30}, {Центр крови ФМБА России} |
| Кнопка 1 (красная) | Отменить запись |
| Кнопка 2 (контурная) | Оставить |

## Переходы

| Действие | Куда |
|----------|------|
| Карточка «Донорский светофор» | Экран «Карта» на весь экран |
| «Записаться» | Экран «Запись на донорство» (`Процесс записи/Запись 0.1 — Запись на донорство.md`) |
| «Перенести» | Шаг 2 «Дата», вид и регион уже выбраны (см. `0 Запись — общие правила.md`, «Перенос записи») |
| «Отменить» | Окно подтверждения отмены |
| «Отменить запись» в окне | Запись отменяется, карточка переходит в вариант А, внизу уведомление «Запись отменена» на 2 секунды |
| «Оставить» в окне | Окно закрывается |
| Вкладка «Личный кабинет» | Экран «Личный кабинет» |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Загрузка | Серые заглушки на месте обеих карточек |
| Ошибка загрузки записи | В карточке записи: «Не удалось загрузить запись» и кнопка «Повторить». Карта работает |
| Карта не загрузилась | В превью серый фон с иконкой карты, карточка остаётся нажимаемой |
| Отмена в процессе | На кнопке «Отменить запись» спиннер |
| Ошибка отмены | Окно закрывается, уведомление «Не удалось отменить запись. Попробуйте ещё раз», запись остаётся |

## Сообщения бота (напоминание)

За день до донации бот присылает в чат MAX:

> Завтра в {09:30} вы сдаёте {цельную кровь} в {Центр крови ФМБА России}, {ул. Поликарпова, 14}.
>
> Как подготовиться:
> • не пейте алкоголь
> • не ешьте жирное, жареное, острое и копчёное
> • утром легко позавтракайте
> • возьмите паспорт
>
> [Открыть запись]

Кнопка «Открыть запись» открывает мини-приложение на вкладке «Запись».
