# Запись. Шаг 5 — Проверьте запись

## Структура

```
┌──────────────────────────────┐
│ [←]  Проверьте запись        │
│      Шаг 5 из 5              │
│ ▬▬▬ ▬▬▬ ▬▬▬ ▬▬▬ ▬▬▬          │
│ ┌──────────────────────────┐ │
│ │ Вид донации    Изменить  │ │
│ │ Цельная кровь            │ │
│ │──────────────────────────│ │
│ │ Центр          Изменить  │ │
│ │ Центр крови ФМБА России  │ │  сводка
│ │ ул. Поликарпова, 14      │ │
│ │──────────────────────────│ │
│ │ Дата и время   Изменить  │ │
│ │ 14 октября, вт, 09:30    │ │
│ │──────────────────────────│ │
│ │ Донор                    │ │
│ │ Иванов Иван Иванович     │ │
│ │ +7 (900) 123-45-67       │ │
│ └──────────────────────────┘ │
│  🔔 Напомним в чате за день  │
│  Не забудьте паспорт         │
│ [       Записаться        ]  │
└──────────────────────────────┘
```

## Элементы и тексты

Одна карточка на всю ширину, разделы через тонкую линию. В каждом разделе подпись мелким серым, справа ссылка «Изменить» фирменным цветом, ниже значение.

| Раздел | Значение | «Изменить» ведёт на |
|--------|----------|---------------------|
| Вид донации | {Цельная кровь} | Шаг 1 |
| Центр | {Центр крови ФМБА России}, ниже мелко адрес | Шаг 3 |
| Дата и время | {14 октября, вторник, 09:30} | Шаг 2 |
| Донор | ФИО, телефон | Ссылки нет |

Под карточкой, мелким серым, с иконками:
- 🔔 Напомним в чате MAX за день до донации
- 🪪 Не забудьте паспорт

**Кнопка:** Записаться — основная, закреплена внизу.

## Переходы

| Действие | Куда |
|----------|------|
| «Изменить» | Соответствующий шаг. После нового выбора пользователь снова проходит шаги до 5 |
| «Записаться» | Экран «Вы записаны» |
| «←» | Шаг 4 |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Отправка | Спиннер на кнопке «Записаться», повторно нажать нельзя |
| Ошибка сети | Уведомление «Не удалось записаться. Проверьте интернет и попробуйте ещё раз», пользователь остаётся на экране |
| Слот уже заняли | Окно «Это время уже заняли» с кнопкой «Выбрать другое время» → шаг 4 |
