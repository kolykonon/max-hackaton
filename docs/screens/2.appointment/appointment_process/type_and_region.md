│ [←]  Вид донации и регион    │

## Элементы и тексты

### Вид донации

| Элемент | Вид | Текст |
|---------|-----|-------|
| Подзаголовок | Жирный | Что будете сдавать |
| Переключатель | Два сегмента на всю ширину, выбранный залит фирменным цветом, в каждом маленькая капля слева | Цельная кровь · Плазма |
| Подпись | Мелкий серый. Показывается, только если интервал после прошлой донации ещё не прошёл | {Цельную кровь / Плазму} можно сдать с {12 октября} |

По умолчанию выбрана «Цельная кровь».

### Регион

| Элемент | Вид | Текст |
|---------|-----|-------|
| Подзаголовок | Жирный | Регион |
| Регион по геолокации | Строка-карточка с иконкой метки, фирменная рамка, если выбран | {Москва} · по вашей геопозиции |
| Поиск | Поле с иконкой лупы | плейсхолдер: Поиск региона |
| Список | Все регионы РФ по алфавиту, строки с тонким разделителем. Выбранный — с галочкой справа | Названия регионов |

- Поиск фильтрует список по мере ввода, без учёта регистра.
- Если по запросу ничего нет: «Регион не найден».
- Если в регионе нет центров в демо-данных, строка серая и подпись «Нет центров для записи», выбрать нельзя.

### Кнопка

**Далее** — активна, когда выбран регион.

## Переходы

| Действие | Куда |
|----------|------|
| Выбор вида | Сегмент выделяется |
| Нажатие на регион | Регион выбирается, галочка |
| «Далее» | Шаг 2 «Дата» |
| «←» | Экран «Подтверждение данных» |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Первое открытие | Запрос геолокации. Если разрешили — регион подставлен и выбран. Если нет — строки «по геопозиции» нет, ничего не выбрано |
| Загрузка списка | Серые строки-заглушки |
| Ошибка загрузки | «Не удалось загрузить регионы» и кнопка «Повторить» |
