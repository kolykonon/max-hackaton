# Запись. Экран «Вы записаны»

Показывается после успешной записи. Шапки и стрелки «Назад» нет, нижнее меню скрыто.

## Структура

```
┌──────────────────────────────┐
│                              │
│          [ ✓ ]               │  иконка успеха
│                              │
│       Вы записаны!           │
│  Спасибо, что помогаете      │
│                              │
│ ┌──────────────────────────┐ │
│ │ 14 октября, вт, 09:30    │ │
│ │ Цельная кровь            │ │  детали
│ │ Центр крови ФМБА России  │ │
│ │ ул. Поликарпова, 14      │ │
│ └──────────────────────────┘ │
│                              │
│  Как подготовиться           │
│  • Не пейте алкоголь 2 дня   │  памятка
│  • Не ешьте жирное ...       │
│  • Легко позавтракайте       │
│  • Возьмите паспорт          │
│                              │
│  Подтверждение отправили     │
│  в чат                       │
│ [       На главную        ]  │
└──────────────────────────────┘
```

## Элементы и тексты

| Элемент | Вид | Текст |
|---------|-----|-------|
| Иконка | Большая зелёная галочка в круге | — |
| Заголовок | Крупный жирный, по центру | Вы записаны! |
| Подзаголовок | Обычный, по центру | Спасибо, что помогаете тем, кому нужна кровь |
| Карточка записи | Дата и время жирным, ниже вид (с каплей), центр, адрес мелко | {14 октября, вторник, 09:30} · {Цельная кровь} · {Центр крови ФМБА России} · {ул. Поликарпова, 14} |
| Памятка | Подзаголовок жирным и список | Как подготовиться<br>• Не пейте алкоголь за 2 дня до донации<br>• Накануне не ешьте жирное, жареное, острое и копчёное<br>• Утром легко позавтракайте<br>• Возьмите паспорт |
| Подпись | Мелкий серый, иконка чата | Подтверждение и памятку отправили вам в чат. Напомним за день до донации |
| Кнопка | Основная, на всю ширину | На главную |

## Сообщение бота в чат

Сразу после записи бот присылает:

> Вы записаны на донацию ✅
> {14 октября, вторник, 09:30}
> {Цельная кровь}, {Центр крови ФМБА России}, {ул. Поликарпова, 14}
>
> Не забудьте паспорт. Напомним за день до донации.
>
> [Открыть запись]

## Переходы

| Действие | Куда |
|----------|------|
| «На главную» или системный «Назад» | Экран «Запись», карточка «Вы записаны» |
| «Открыть запись» в чате | Мини-приложение на экране «Запись» |
