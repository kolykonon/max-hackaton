# Экран «Запись на донорство»

Открывается кнопкой «Записаться» на экране «Запись». Нижнее меню на этом экране скрыто.

## Структура

```
┌──────────────────────────────┐
│ [←]  Запись на донорство     │  шапка
│ ┄┄┄┄┄┄┄ прокрутка ┄┄┄┄┄┄┄┄┄  │
│ ┌──────────────────────────┐ │
│ │ Воспользуйтесь льготами  │ │  зона 1
│ │ донора                   │ │
│ │ • Выходной в день ...    │ │
│ │ • Доп. день отдыха       │ │
│ │ • Бесплатное питание     │ │
│ │ Все льготы и привилегии ›│ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ Кто может сдавать кровь  │ │  зона 2
│ │ ✓ От 18 лет              │ │
│ │ ✓ Вес от 50 кг           │ │
│ │ ✓ 60 дней с прошлой сдачи│ │
│ │ Почему такие ограничения?›│ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ Противопоказания         │ │  зона 3
│ │ • ВИЧ, гепатиты B и C ...│ │
│ │ • Алкоголь — 48 часов    │ │
│ │ • ОРВИ — 30 дней ...     │ │
│ │ Полный список           ›│ │
│ └──────────────────────────┘ │
│ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│ [       Записаться        ]  │  кнопка (закреплена)
└──────────────────────────────┘
```

Три зоны — карточки на всю ширину друг под другом. Экран прокручивается, шапка и кнопка закреплены.

## Элементы и тексты

### 1. Шапка

| Элемент | Вид | Текст |
|---------|-----|-------|
| Кнопка «Назад» | Стрелка «←» слева | скринридер: «Назад» |
| Заголовок | Жирный | Запись на донорство |

### 2. Зона «Льготы»

| Элемент | Вид | Текст |
|---------|-----|-------|
| Иконка | Подарок, ~32 px, слева от заголовка | — |
| Заголовок | Жирный | Воспользуйтесь льготами донора |
| Список | 3 пункта, маркер-точка | • Освобождение от работы в день донации с сохранением заработка<br>• Дополнительный оплачиваемый день отдыха<br>• Бесплатное питание или компенсация |
| Ссылка | Фирменный цвет, справа «›» | Все льготы и привилегии |

### 3. Зона «Кто может сдавать кровь»

| Элемент | Вид | Текст |
|---------|-----|-------|
| Иконка | Человек с галочкой, ~32 px | — |
| Заголовок | Жирный | Кто может сдавать кровь |
| Список | 3 пункта, зелёная галочка | ✓ Вам есть 18 лет<br>✓ Вы весите не меньше 50 кг<br>✓ С прошлой сдачи цельной крови прошло не меньше 60 дней |
| Ссылка | Фирменный цвет, справа «›» | Почему такие ограничения? |

### 4. Зона «Противопоказания»

| Элемент | Вид | Текст |
|---------|-----|-------|
| Иконка | Щит с восклицательным знаком, ~32 px | — |
| Заголовок | Жирный | Противопоказания |
| Список | 3 пункта, маркер-точка | • ВИЧ, гепатиты B и C, сифилис, туберкулёз — сдавать нельзя<br>• После алкоголя — подождите 48 часов<br>• После ОРВИ и гриппа — 30 дней после выздоровления |
| Ссылка | Фирменный цвет, справа «›» | Полный список противопоказаний |

### 5. Кнопка

Основная, фирменный цвет, на всю ширину, закреплена внизу. Текст: **Записаться**.

## Переходы

| Действие | Куда |
|----------|------|
| «←» или системный «Назад» | Экран «Запись» |
| «Все льготы и привилегии» | Шторка «Льготы и привилегии» (`Модалка — Льготы и привилегии.md`) |
| «Почему такие ограничения?» | Шторка «Почему такие ограничения» (`Модалка — Почему такие ограничения.md`) |
| «Полный список противопоказаний» | Шторка «Противопоказания» (`Модалка — Противопоказания.md`) |
| «Записаться» | Экран подтверждения документов |
