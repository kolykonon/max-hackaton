# Экран «Подтверждение данных»

Открывается кнопкой «Записаться» на экране «Запись на донорство». Нижнее меню скрыто. В MVP поля заполнены демо-данными, как будто они пришли из Госуслуг.

## Структура

**Режим просмотра:**

```
┌──────────────────────────────┐
│ [←]  Проверьте данные        │  шапка
│ ┄┄┄┄┄┄┄ прокрутка ┄┄┄┄┄┄┄┄┄  │
│  Эти данные нужны центру     │  подзаголовок
│  крови для записи      Демо  │
│ ┌──────────────────────────┐ │
│ │ Паспорт РФ               │ │
│ │ ФИО                      │ │
│ │ Иванов Иван Иванович     │ │
│ │ Серия и номер            │ │  блок «Паспорт»
│ │ 4510 123456              │ │
│ │ Кем выдан                │ │
│ │ ГУ МВД России по г. Москве│ │
│ │ Код подразделения        │ │
│ │ 770-001                  │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ Полис ОМС                │ │  блок «Полис»
│ │ 1234 5678 9012 3456      │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ Контакты                 │ │
│ │ Телефон                  │ │  блок «Контакты»
│ │ +7 (900) 123-45-67       │ │
│ │ Эл. почта                │ │
│ │ ivanov@mail.ru           │ │
│ └──────────────────────────┘ │
│ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│ [Данные неверны] [  Далее  ] │  кнопки (закреплены)
└──────────────────────────────┘
```

**Режим редактирования:** те же блоки, но вместо текста поля ввода, внизу кнопки «Отмена» и «Сохранить».

## Элементы и тексты

### 1. Шапка

| Элемент | Вид | Текст |
|---------|-----|-------|
| Кнопка «Назад» | Стрелка «←» слева | скринридер: «Назад» |
| Заголовок | Жирный | Проверьте данные |
| Подзаголовок | Мелкий серый, под шапкой | Эти данные нужны центру крови для записи |
| Метка | Мелкий серый на светлом фоне, справа от подзаголовка | Демо-данные |

### 2. Блоки данных

Три карточки на всю ширину. В каждой заголовок жирным, ниже пары «подпись мелким серым — значение обычным».

**Паспорт РФ**

| Подпись | Пример значения |
|---------|-----------------|
| ФИО | Иванов Иван Иванович |
| Серия и номер | 4510 123456 |
| Кем выдан | ГУ МВД России по г. Москве |
| Код подразделения | 770-001 |

**Полис ОМС**

| Подпись | Пример значения |
|---------|-----------------|
| Номер полиса | 1234 5678 9012 3456 |

**Контакты**

| Подпись | Пример значения |
|---------|-----------------|
| Телефон | +7 (900) 123-45-67 |
| Эл. почта | ivanov@mail.ru |

### 3. Кнопки (режим просмотра)

| Кнопка | Вид | Текст |
|--------|-----|-------|
| Левая | Контурная, половина ширины | Данные неверны |
| Правая | Основная, фирменный цвет, половина ширины | Далее |

### 4. Режим редактирования

Все значения превращаются в поля ввода с подписью сверху. Заголовок шапки меняется на «Изменение данных».

| Поле | Клавиатура | Формат / маска | Ошибка |
|------|-----------|----------------|--------|
| Фамилия | Текст | Буквы, дефис | Введите фамилию |
| Имя | Текст | Буквы, дефис | Введите имя |
| Отчество | Текст | Необязательное | — |
| Серия | Цифры | 4 цифры | Серия — 4 цифры |
| Номер | Цифры | 6 цифр | Номер — 6 цифр |
| Кем выдан | Текст | — | Укажите, кем выдан паспорт |
| Код подразделения | Цифры | 000-000 | Код подразделения — 6 цифр |
| Номер полиса | Цифры | 0000 0000 0000 0000 | Номер полиса — 16 цифр |
| Телефон | Телефон | +7 (000) 000-00-00 | Введите номер телефона полностью |
| Эл. почта | Email | — | Проверьте адрес почты |

ФИО в режиме редактирования разбито на три поля. Ошибка показывается красным под полем после того, как пользователь ушёл с поля или нажал «Сохранить».

| Кнопка | Вид | Текст |
|--------|-----|-------|
| Левая | Контурная, половина ширины | Отмена |
| Правая | Основная, половина ширины | Сохранить |

## Переходы

| Действие | Куда |
|----------|------|
| «←» или системный «Назад» | Экран «Запись на донорство» |
| «Данные неверны» | Режим редактирования, фокус на первом поле |
| «Отмена» | Режим просмотра, изменения не сохраняются |
| «Сохранить» без ошибок | Режим просмотра с новыми данными, уведомление «Данные сохранены» на 2 секунды |
| «Сохранить» с ошибками | Остаётся режим редактирования, экран прокручивается к первому полю с ошибкой |
| «Далее» | Шаг 1 «Вид донации и регион» (`Запись 1 — Вид и регион.md`) |
| «←» в режиме редактирования с изменениями | Окно «Выйти без сохранения?» с кнопками «Выйти» и «Остаться» |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Загрузка | Серые заглушки на месте блоков, кнопки неактивны |
| Ошибка загрузки | По центру: «Не удалось загрузить данные» и кнопка «Повторить» |
| Сохранение | На кнопке «Сохранить» спиннер |
| Ошибка сохранения | Уведомление «Не удалось сохранить. Попробуйте ещё раз», остаётся режим редактирования |
| Не хватает данных | Пустое обязательное поле в режиме просмотра показано как «Не указано» красным, кнопка «Далее» неактивна |
