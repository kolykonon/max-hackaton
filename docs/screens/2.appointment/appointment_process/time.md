# Запись. Шаг 4 — Время

## Структура

```
┌──────────────────────────────┐
│ [←]  Выберите время          │
│      Шаг 4 из 5              │
│ ▬▬▬ ▬▬▬ ▬▬▬ ▬▬▬ ───          │
│  Центр крови ФМБА России     │
│  14 октября, вторник         │
│                              │
│  Утро                        │
│ [08:00][08:15][08:30][08:45] │
│ [09:00][09:15][09:30][09:45] │  слоты
│ [10:00][10:15][10:30][10:45] │
│  День                        │
│ [12:00][12:15][12:30][12:45] │
│ ...                          │
│ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│ [          Далее          ]  │
└──────────────────────────────┘
```

## Элементы и тексты

| Элемент | Вид | Текст |
|---------|-----|-------|
| Центр | Жирный | {Центр крови ФМБА России} |
| Дата | Мелкий серый | {14 октября, вторник} |
| Группа слотов | Подзаголовок жирным | Утро (до 12:00) · День (12:00–17:00) · Вечер (после 17:00). Пустые группы не показываются |
| Слот | Карточка-кнопка, 4 в ряд, время по центру | 08:00, 08:15, 08:30 … с шагом 15 минут |

### Вид слота

| Слот | Вид | Нажимается |
|------|-----|------------|
| Свободен | Белый фон, рамка, обычный текст | Да |
| Занят | Серый фон, серый текст | Нет |
| Выбран | Заливка фирменным цветом, белый текст | — |

### Кнопка

**Далее** — активна, когда выбран слот.

## Переходы

| Действие | Куда |
|----------|------|
| Нажатие на свободный слот | Слот выбирается |
| «Далее» | Шаг 5 «Проверьте запись» |
| «←» | Шаг 3 |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Загрузка | Серые слоты-заглушки |
| Ошибка загрузки | «Не удалось загрузить время» и кнопка «Повторить» |
| Все слоты заняты | «На этот день всё занято» и кнопки «Другой центр» (шаг 3) и «Другая дата» (шаг 2) |
