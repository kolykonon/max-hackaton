# Запись: общие правила

Порядок экранов записи:

```
Запись (главный) → «Записаться»
  → Запись на донорство (льготы, ограничения, противопоказания)
  → Подтверждение данных
  → Шаг 1. Вид донации и регион
  → Шаг 2. Дата
  → Шаг 3. Центр крови (список / карта)
  → Шаг 4. Время
  → Шаг 5. Проверьте запись
  → Вы записаны
  → Запись (главный), карточка «Вы записаны»
```

| Шаг | Файл |
|-----|------|
| 1 | `Запись 1 — Вид и регион.md` |
| 2 | `Запись 2 — Дата.md` |
| 3 | `Запись 3 — Центр крови.md` |
| 4 | `Запись 4 — Время.md` |
| 5 | `Запись 5 — Проверьте запись.md` |
| — | `Запись 6 — Вы записаны.md` |

## Общее для шагов 1–5

- Нижнее меню скрыто.
- Шапка: стрелка «←» слева и заголовок шага. Под заголовком мелким серым «Шаг {N} из 5».
- Под шапкой тонкий прогресс-бар из 5 сегментов, закрашены пройденные и текущий.
- Кнопка «Далее» закреплена внизу, на всю ширину. Пока выбор не сделан, она неактивна.
- «←» или системный «Назад» возвращает на предыдущий шаг, сделанный выбор сохраняется.
- Если на шаге 1–4 поменять выбор, всё, что выбрано на следующих шагах и зависит от него, сбрасывается.
- Слоты и даты в MVP — демо-данные.

## Перенос записи

Кнопка «Перенести» на главном экране открывает сразу шаг 2 «Дата». Вид донации и регион уже выбраны как в текущей записи, а на шаге 3 текущий центр стоит первым в списке. На шаге 5 заголовок «Проверьте новую запись», кнопка «Перенести запись». После подтверждения старая запись отменяется.
