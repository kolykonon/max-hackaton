# Модалка «Уровни донора»

Открывается из «Личного кабинета» нажатием на блок уровня донора. Это шторка снизу поверх экрана, фон под ней затемняется.

## Структура

```
┌──────────────────────────────┐
│            ────              │  полоска-ручка
│  Уровни донора           [✕] │  заголовок
│  Уровень растёт с каждой     │  подзаголовок
│  донацией крови или плазмы   │
│                              │
│  [✓] Новичок                 │
│      от 1 донации   Получен  │
│  [✓] Активный донор          │
│      от 5 донаций   Получен  │
│ ┌──────────────────────────┐ │
│ │[●] Опытный донор         │ │  текущий уровень
│ │    от 10 донаций  Ваш    │ │  (выделен)
│ │    уровень               │ │
│ └──────────────────────────┘ │
│  [🔒] Наставник              │
│      от 20 донаций           │
│      Осталось 8 донаций      │
│  [🔒] Легенда донорства      │
│      от 40 донаций           │
│      Осталось 28 донаций     │
└──────────────────────────────┘
```

Высота шторки подстраивается под содержимое, но не больше 80% экрана. Если не помещается, содержимое прокручивается.

## Элементы и тексты

| Элемент | Вид | Текст |
|---------|-----|-------|
| Ручка | Короткая серая полоска по центру сверху | — |
| Заголовок | Крупный жирный, слева | Уровни донора |
| Кнопка закрытия | Крестик справа от заголовка | скринридер: «Закрыть» |
| Подзаголовок | Мелкий серый | Уровень растёт с каждой донацией крови или плазмы |
| Список уровней | 5 строк сверху вниз, от младшего к старшему | см. ниже |

### Строка уровня

Слева значок уровня ~40 px, справа столбиком: название жирным, порог мелким серым, статус.

| Уровень | Порог |
|---------|-------|
| Новичок | от 1 донации |
| Активный донор | от 5 донаций |
| Опытный донор | от 10 донаций |
| Наставник | от 20 донаций |
| Легенда донорства | от 40 донаций |

### Вид строки в зависимости от статуса

| Статус | Значок | Строка | Текст статуса |
|--------|--------|--------|---------------|
| Получен | Цветной значок уровня с галочкой | Обычный фон | Получен (зелёный) |
| Текущий | Цветной значок уровня | Фон в светлом фирменном цвете, рамка | Ваш уровень (фирменный цвет) |
| Не получен | Серый значок с замком | Текст серый | Осталось {M} донаций |

Если у пользователя 0 донаций, все уровни «Не получен», а над списком показывается строка: «Сдайте кровь в первый раз — и получите уровень «Новичок»».

## Переходы

| Действие | Куда |
|----------|------|
| Крестик, свайп вниз или тап по затемнению | Шторка закрывается, пользователь в «Личном кабинете» на том же месте |
| Нажатие на строку уровня | Ничего не происходит |
