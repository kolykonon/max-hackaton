# Модалка «История донаций»

Открывается из «Личного кабинета» кнопкой «История донаций». Шторка снизу поверх экрана, фон затемняется. Данные в MVP тестовые.

## Структура

```
┌──────────────────────────────┐
│            ────              │  ручка
│  История донаций         [✕] │  заголовок
│  Всего 12 донаций   Демо     │  подзаголовок + метка
│ ┄┄┄┄┄┄┄ прокрутка ┄┄┄┄┄┄┄┄┄  │
│  2026 · 3 донации            │  заголовок года
│ ┌──────────────────────────┐ │
│ │[капля] Цельная кровь     │ │
│ │        14 августа        │ │  донация
│ │        Центр крови ФМБА  │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │[капля] Плазма            │ │
│ │        2 июня            │ │
│ │        ГКБ им. ...       │ │
│ └──────────────────────────┘ │
│  ...                         │
│  2025 · 5 донаций            │
│ ┌──────────────────────────┐ │
│ │ ...                      │ │
└──────────────────────────────┘
```

Высота до 90% экрана. Шапка закреплена, список прокручивается. Заголовок года при прокрутке прилипает к верху списка, пока видны донации этого года.

## Элементы и тексты

| Элемент | Вид | Текст |
|---------|-----|-------|
| Ручка | Серая полоска по центру сверху | — |
| Заголовок | Крупный жирный, слева | История донаций |
| Кнопка закрытия | Крестик справа | скринридер: «Закрыть» |
| Подзаголовок | Мелкий серый | Всего {N} донаций |
| Метка | Мелкий серый текст на светлом фоне, справа от подзаголовка | Демо-данные |
| Заголовок года | Жирный, слева | {Год} · {K} донаций |
| Карточка донации | На всю ширину. Слева картинка вида ~32 px, справа столбиком три строки | см. ниже |

### Карточка донации

| Строка | Вид | Пример |
|--------|-----|--------|
| Вид донации | Жирный | Цельная кровь / Плазма |
| Дата | Обычный | 14 августа |
| Клиника | Мелкий серый, при длинном названии переносится на 2 строки | Центр крови ФМБА России |

Картинка вида та же, что в карточках целей: красная капля для крови, жёлтая для плазмы.

### Порядок

- Годы от нового к старому.
- Внутри года донации от новой к старой.
- Год в дате карточки не пишется, он уже в заголовке.

## Переходы

| Действие | Куда |
|----------|------|
| Крестик, свайп вниз или тап по затемнению | Шторка закрывается, пользователь в «Личном кабинете» на том же месте |
| Нажатие на карточку донации | Ничего не происходит |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Загрузка | 3 серые карточки-заглушки |
| Ошибка загрузки | По центру: «Не удалось загрузить историю» и кнопка «Повторить» |
| Нет донаций | По центру картинка капли и текст «Здесь появятся ваши донации», подзаголовок «Всего 0 донаций» |
