# Онбординг: общие правила

Мини-приложение в MAX, которое открывается из чат-бота. Онбординг состоит из 3 экранов:

| № | Экран | Файл |
|---|-------|------|
| 1 | Приветствие | `Экран 1 — Приветствие.md` |
| 2 | Что получает донор | `Экран 2 — Что получает донор.md` |
| 3 | Кто может сдать кровь | `Экран 3 — Кто может сдать кровь.md` |

## Вход в приложение

```
Запуск мини-приложения
        │
        ▼
Проверка по ID пользователя MAX: онбординг пройден и согласие дано?
        │
        ├── Да ─────────────► Вкладка «Запись»
        ├── Нет ────────────► Экран 1
        └── Ошибка проверки ► Экран 1
```

Пока идёт проверка, на экране по центру крутится индикатор загрузки, без текста.

## Навигация

- Сверху прогресс-бар из 3 сегментов, как в сторис: пройденные и текущий сегмент закрашены, остальные серые. Нажимать на него нельзя.
- Экраны переключаются только вручную, автопереключения нет.
- Вперёд: кнопка «→» или свайп влево. Назад: кнопка «←» или свайп вправо.
- Кнопки «Пропустить» нет.
- Если закрыть приложение посреди онбординга, при следующем запуске он начнётся с экрана 1.

| Экран | «←» / свайп вправо | «→» / свайп влево |
|-------|--------------------|-------------------|
| 1 | — | Экран 2 |
| 2 | Экран 1 | Экран 3 |
| 3 | Экран 2 | — (вместо стрелки кнопка «Начать» → вкладка «Запись») |
