# Экран 3. Кто может сдать кровь

## Структура (сверху вниз)

```
┌──────────────────────────────┐
│ ▬▬▬▬  ▬▬▬▬  ▬▬▬▬             │  прогресс-бар, 3 из 3 (закреплён)
│ ┄┄┄┄┄┄┄ прокрутка ┄┄┄┄┄┄┄┄┄  │
│       [ Иллюстрация ]        │  по центру, ~15–20% высоты
│                              │
│  Кто может сдать кровь       │  заголовок
│                              │
│  ✓ Вам есть 18 лет           │
│  ✓ Вы весите от 50 кг        │
│  ✓ Гражданство РФ или ...    │  чек-лист, 6 пунктов
│  ✓ С прошлой сдачи 60 дней   │
│  ✓ Нет противопоказаний      │
│  ✓ Паспорт с собой           │
│                              │
│  [ Список противопоказаний ] │  кнопка → шторка
│                              │
│  Окончательное решение...    │  дисклеймер
│                              │
│  ☐ Я соглашаюсь на обработку │  чекбокс согласия
│    персональных данных       │
│ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│ [←]        [   Начать   ]    │  кнопки (закреплены)
└──────────────────────────────┘
```

Средняя часть прокручивается по вертикали. Прогресс-бар и кнопки всегда на месте.

| # | Элемент | Вид | Текст |
|---|---------|-----|-------|
| 1 | Прогресс-бар | 3 сегмента, закрашены все | — |
| 2 | Иллюстрация | Планшет с галочками и каплей крови | alt: «Иллюстрация: планшет с чек-листом» |
| 3 | Заголовок | Крупный жирный | Кто может сдать кровь |
| 4 | Чек-лист | 6 пунктов, слева зелёная галочка. Нажимать на пункты нельзя | см. ниже |

### Чек-лист

1. Вам есть 18 лет
2. Вы весите не меньше 50 кг
3. У вас гражданство России, или вы законно живёте в России не меньше года
4. С прошлой сдачи цельной крови прошло не меньше 60 дней
5. У вас нет противопоказаний
6. У вас с собой паспорт

## Шторка «Противопоказания»

Общая с экраном «Запись на донорство»: `2 Вкладка Запись/Модалки/Модалка — Противопоказания.md`.

## Переходы

| Действие | Куда |
|----------|------|
| «Список противопоказаний» | Открывается шторка |
| Крестик, свайп вниз или тап по затемнению | Шторка закрывается, пользователь на экране 3 в том же месте прокрутки |
| «Полный список на сайте Службы крови» | yadonor.ru во внешнем браузере |
| Ссылка «обработку персональных данных» | Текст согласия на обработку персональных данных |
| «Начать» при отмеченном согласии | Вкладка «Запись» |
| «Начать» без согласия | Никуда. Появляется подсказка к чекбоксу |
| «←» или свайп вправо | Экран 2, галочка согласия сохраняется |
| Свайп влево | Никуда, это последний экран |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Нет согласия | Кнопка «Начать» серая |
| Согласие дано | Кнопка «Начать» в фирменном цвете |
| Сохранение | На кнопке «Начать» спиннер вместо текста, нажать повторно нельзя |
| Ошибка сохранения | Появляется сообщение об ошибке, кнопка «Начать» снова активна, галочка остаётся |
| Успех | Переход на вкладку «Запись», онбординг больше не показывается |
| Картинка не загрузилась | Экран без картинки, остальное без изменений |
