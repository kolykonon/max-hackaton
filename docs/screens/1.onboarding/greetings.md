# Экран 1. Приветствие

## Структура (сверху вниз)

```
┌──────────────────────────────┐
│ ▬▬▬▬  ────  ────             │  прогресс-бар, 1 из 3
│                              │
│                              │
│        [ Иллюстрация ]       │  чуть выше центра, ~35–40% высоты
│                              │
│                              │
│  Спасибо, что решили         │  заголовок
│  стать донором               │
│                              │
│  Сдать кровь — значит помочь │  основной текст
│  тому, кто прямо сейчас...   │
│                              │
│                         [→]  │  кнопка «Далее»
└──────────────────────────────┘
```

Экран не прокручивается: всё помещается целиком.

## Элементы и тексты

| # | Элемент | Вид | Текст |
|---|---------|-----|-------|
| 1 | Прогресс-бар | 3 сегмента, закрашен 1-й | — |
| 2 | Иллюстрация | Картинка про донорство (капля крови, сердце, рука с пластырем), по центру | alt: «Иллюстрация: капля крови в ладонях» |
| 3 | Заголовок | Крупный жирный, по центру | Спасибо, что решили стать донором |
| 4 | Основной текст | Обычный, по центру | Сдать кровь — значит помочь тому, кто прямо сейчас в ней нуждается. Мы расскажем, как подготовиться, и поможем на каждом шаге. |
| 5 | Кнопка «→» | Круглая, фирменный цвет, правый нижний угол | подпись для скринридера: «Далее» |

## Переходы

| Действие | Куда |
|----------|------|
| «→» или свайп влево | Экран 2 |
| Свайп вправо | Никуда, это первый экран |

## Состояния

| Состояние | Что видно |
|-----------|-----------|
| Картинка грузится | Серый плейсхолдер того же размера |
| Картинка не загрузилась | Экран без картинки, остальное без изменений |
