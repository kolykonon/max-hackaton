# Экран 2. Что получает донор

## Структура (сверху вниз)

```
┌──────────────────────────────┐
│ ▬▬▬▬  ▬▬▬▬  ────             │  прогресс-бар, 2 из 3 (закреплён)
│ ┄┄┄┄┄┄┄ прокрутка ┄┄┄┄┄┄┄┄┄  │
│       [ Иллюстрация ]        │  по центру, ~20–25% высоты
│                              │
│  Что вы получаете            │  заголовок
│  при каждой донации          │
│                              │
│  [иконка] Освобождение ...   │
│  [иконка] Дополнительный ... │  4 карточки льгот
│  [иконка] Бесплатное мед...  │
│  [иконка] Бесплатное пит...  │
│                              │
│  ┌────────────────────────┐  │
│  │ Почётный донор России  │  │  выделенный блок
│  └────────────────────────┘  │
│ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│ [←]                     [→]  │  кнопки (закреплены)
└──────────────────────────────┘
```

Средняя часть прокручивается по вертикали. Прогресс-бар и кнопки всегда на месте.

## Элементы и тексты

| # | Элемент | Вид | Текст |
|---|---------|-----|-------|
| 1 | Прогресс-бар | 3 сегмента, закрашены 1-й и 2-й | — |
| 2 | Иллюстрация | Подарок и капля крови, по центру | alt: «Иллюстрация: подарок и капля крови» |
| 3 | Заголовок | Крупный жирный | Что вы получаете при каждой донации |
| 4 | Карточки льгот | 4 карточки: иконка слева, заголовок жирным, пояснение обычным | см. таблицу ниже |
| 5 | Блок «Почётный донор России» | Карточка с цветным фоном и иконкой медали | см. ниже |
| 6 | Кнопка «←» | Круглая, контурная, слева внизу | скринридер: «Назад» |
| 7 | Кнопка «→» | Круглая, фирменный цвет, справа внизу | скринридер: «Далее» |

### Карточки льгот

| Иконка | Заголовок | Пояснение |
|--------|-----------|-----------|
| Календарь | Освобождение от работы в день донации | С сохранением среднего заработка |
| Шезлонг | Дополнительный оплачиваемый день отдыха | Можно взять сразу, присоединить к отпуску или использовать в течение года |
| Планшет с крестом | Бесплатное медобследование | Перед донацией проверят группу крови, резус-фактор, гемоглобин и инфекции |
| Тарелка | Бесплатное питание | В день донации. Или денежная компенсация вместо питания |

### Блок «Почётный донор России»

> **Почётный донор России**
>
> Звание дают, если вы сдали кровь 40 раз или плазму 60 раз.
>
> **Что даёт звание:**
> - ежегодную выплату — 19 497,68 ₽ в 2026 году;
> - медицинскую помощь вне очереди в государственных медучреждениях;
> - отпуск в удобное для вас время;
> - первоочередную покупку льготных путёвок в санаторий.

| Состояние | Что видно |
|-----------|-----------|

| Картинка не загрузилась | Экран без картинки, остальное без изменений |
