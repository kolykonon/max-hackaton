# Источники справочника центров крови

Это **статический снимок открытых данных, не живая интеграция**.
При запуске используется только локальный `centers.json`; сайты не опрашиваются.

| Поле | Сведения |
|---|---|
| Файл и объём | `centers.json`, 405 центров; `regions.json`, 89 записей регионов |
| Территория | Российский справочник службы крови, центры представлены в 84 регионах; охват и названия сохранены из исходного набора, это не оценка правового статуса территорий |
| Дата проверки записей | 2026-09-27, поле `verified_on` у всех 405 центров |
| Дата выгрузки | Отдельно не зафиксирована; **ДОПУЩЕНИЕ:** дата снимка 2026-09-27 по `verified_on`, точное время выгрузки неизвестно |
| Исходная таблица | `legacy/russia-map/data/raw/blood_stations_russia.csv` в репозитории |
| Основной источник | [НМИЦ гематологии — где сдать кровь](https://donor.blood.ru/contacts/gde-sdat-krov-v-regionakh.php) |
| Дополнительные источники | [Служба крови](https://yadonor.ru/bloodstations/), сайты учреждений и их публичные каналы; точные ссылки сохранены в `source_url` и `source_url_2` каждой записи |
| Лицензия справочника | Явная открытая лицензия исходной таблицы и сайтов в репозитории не указана; право массового переиспользования требует уточнения. Публичная доступность не означает открытую лицензию |
| Координаты | Геокодирование адресов через [Nominatim / OpenStreetMap](https://nominatim.openstreetmap.org/), частично сохранены старые координаты; некоторые точки приблизительные, до уровня города |
| Лицензия геоданных OSM | © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright); эта лицензия не приписывается текстам сайтов учреждений |

Сборка снимка: `backend/scripts/build_centers.py` читает CSV, использует Nominatim
и записывает JSON. Для обычного запуска повторять геокодирование не нужно.
Загрузка в БД: `python -m app.seeds.seed` после `alembic upgrade head`.
Центры сопоставляются по `external_id` и паре регион/название. Повторный запуск
обновляет существующие строки, а слоты защищены уникальным ограничением.

Телефоны, адреса и часы работы могут устареть. Поля `data_status`, `notes` и
`verified_on` позволяют оценить полноту проверки. Статусы запасов крови,
доступность записи и слоты — моделируемые данные; они не получены из МИС центров.
`is_demo=false` в записи означает происхождение справочных сведений, а не
наличие действующей интеграции записи или актуальных запасов крови.

Источники карты и атрибуция тайлов описаны отдельно в `data/SOURCES.md`.
